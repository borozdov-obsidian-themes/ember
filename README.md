# Borozdov Ember

A theme from the Borozdov collection. Two faces — light **Parchment**, cream paper, and
dark **Hearth**, warm soot. Ink-black type, prose set like a book, quiet regular-weight
headlines and one ember-orange accent.

![Borozdov Ember in light mode](https://raw.githubusercontent.com/borozdov-obsidian-themes/ember/main/screenshots/light.png)

![Borozdov Ember in dark mode](https://raw.githubusercontent.com/borozdov-obsidian-themes/ember/main/screenshots/dark.png)

## Principles

- **Paper, not screen.** Cream canvas, bone panels, warm hairlines; the ink is a warm
  near-black, never pure black.
- **Three voices.** A book serif for prose and quotes, the system sans for headlines and
  the interface, a monospace for code, tags and metadata.
- **Headlines whisper.** Regular weight, tightening as they grow — authority from
  restraint, not from bold.
- **One ember.** Links, tags and the caret glow ember-orange; controls stay in ink.
- **Printed corners.** 4px everywhere, 8px only on modals.

## Features

- Light and dark modes, following Settings → Appearance → Base color scheme
- Prose in the platform's book serif: Iowan Old Style on Apple devices, Palatino or Georgia
  elsewhere, EB Garamond if you have it installed — all with true italics and bold
- Callouts on bone paper; the title carries the type's color from a warm palette of
  ember, amber, forest and crimson
- Italic serif pull-quotes behind a thin ember rule
- Code, tags, property names, table headers and the status bar in monospace
- Tables with a hairline frame and grid
- Quiet editing: no focus ring around the note, its title or form fields while you type;
  property names read as labels, not boxed fields
- Link colors meet WCAG contrast: the ember is deepened for text and kept bright only for
  small marks
- About 94 KB with every variant, no fonts embedded, no `!important`

## Variants

Borozdov Ember also carries the other 27 themes of the collection's warm paper & editorial mood. Install the
[Style Settings](https://github.com/mgmeyers/obsidian-style-settings) plugin, open
Settings → Style Settings → **Borozdov Ember** → **Variant**, and pick one: Sienna, Eggshell, Whisper, Folio, Clay, Scholar, Ash, Colophon, Tally, Bulletin, Quarto, Essay, Brief, Broadside, Gazette, Salon, Terracotta, Kernel, Manuscript, Ribbon, Pebble, Cabin, Primer, Memoir, Masthead, Tacet and Monograph.

A variant brings that theme's palette in both modes, its fonts, weights and corners, and
its tag and highlight colours. The layout — callouts, tables, the sidebar — stays
Ember's. Fonts a theme embeds on its own aren't carried over; the variant falls back to
the same system stack. Each theme is still available by itself from its repository.

![Every variant of Borozdov Ember, dark and light](https://raw.githubusercontent.com/borozdov-obsidian-themes/ember/main/screenshots/variants.png)

## Installation

**From the community directory:** Settings → Appearance → Themes → Manage, search for
**Borozdov Ember**, then **Install and use**.

**By hand:** download `manifest.json` and `theme.css` from the
[latest release](https://github.com/borozdov-obsidian-themes/ember/releases/latest) into
`<vault>/.obsidian/themes/Borozdov Ember/`, then choose Borozdov Ember under
Settings → Appearance → Themes.
